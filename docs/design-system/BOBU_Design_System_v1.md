# BOBU Universe Design System v1.0

> The official visual identity and UI/UX standard of BOBU Universe.

---

# Core Vision

BOBU Universe is not just a website.

It is an explorable Web3 social universe where every Builder has a digital identity.

Every screen should feel cinematic, premium and collectible.

# Background Style

Every major page should include:

- Deep space background
- Purple nebula
- Floating particles
- Soft animated stars
- Radial purple glow
- Blur gradients

Never use flat colors.

---

# Cards

Cards should feel like digital collectibles.

Properties

- Rounded XL
- Glassmorphism
- Soft borders
- Purple glow
- Premium shadows

# Animations

Use subtle animations only.

- Floating
- Glow Pulse
- Fade
- Hover Lift

Never use aggressive animations.

---

# Share Cards

Every Builder should be able to generate:

- X Card
- Instagram Story
- Instagram Post
- Profile Banner

Every share card should immediately look like BOBU Universe.

---

# Character Rules

BOBU is always the hero.

Never replace BOBU with another mascot.

Future versions

- Wizard BOBU
- Astronaut BOBU
- Captain BOBU
- Genesis BOBU

All variants must preserve the same identity.

---

# Design Principle

Every page should answer this question:

"Would a user proudly share this screenshot?"

If the answer is no,

redesign it.
